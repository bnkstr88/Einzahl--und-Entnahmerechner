# Anspar- und Entnahmerechner

Installierbare Web-App: Ansparen und Entnehmen mit deutschen Steuern, gesetzlicher Rente und 2.000 möglichen Zukünften von Börse und Inflation.

- Startet mit Beispielwerten. Eigene Eingaben werden nur lokal im Browser des Geräts gespeichert, nichts geht an einen Server.
- Läuft nach dem ersten Öffnen auch offline.
- Installieren: iPhone in Safari → Teilen → „Zum Home-Bildschirm“. Android in Chrome → „App installieren“.

Wie gerechnet wird: [Bericht](https://docs.google.com/document/d/1u9-VBmi0WClI9l4mUbJmswsM6lA1SFn_MFw1z1kqKbE/edit)
